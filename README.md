# osila-css
# CSS Level 2 — Intermediate CSS

This repository contains code examples and practice projects from the CSS Level 2 learning series on [Osila.org](https://osila.org).

 Topics

- CSS Flexbox
- CSS Grid
- Responsive Web Design
- Media Queries
- Pseudo-Classes & Pseudo-Elements
- CSS Variables
- Transform, Transition & Animation
- Object-fit & Object-position
- Z-index & Stacking Context
- Cascade, Specificity & Inheritance
- Responsive Navbar Project
- Responsive Layout Project

## How to Use

1. Open a topic folder.
2. Explore the HTML, CSS, and JavaScript files.
3. Run `index.html` in your browser and practice.
